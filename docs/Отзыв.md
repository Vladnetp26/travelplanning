# ОТЗЫВ НА КУРСОВУЮ РАБОТУ

**Тема:** Разработка веб-приложения для планирования поездок

## Общая характеристика работы

Курсовая работа посвящена разработке веб-приложения для планирования поездок. В работе реализованы все заявленные функции: создание поездок, составление маршрута, учёт расходов, список вещей в чемодане.

## Достоинства работы

- Полнота реализации заявленного функционала
- Использование современных технологий (Django, React, TypeScript, Docker)
- Наличие системы аутентификации
- Качественное оформление пользовательского интерфейса
- Возможность развёртывания в Docker-контейнерах
- Хорошая структурированность кода

## Замечания

- Рекомендуется добавить тесты
- Возможно улучшение мобильной версии интерфейса

## Заключение

Курсовая работа выполнена на высоком уровне, соответствует требованиям и заслуживает оценки «отлично».
