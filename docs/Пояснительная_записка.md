# ПОЯСНИТЕЛЬНАЯ ЗАПИСКА

**Тема:** Разработка веб-приложения для планирования поездок

## 1. Введение

### 1.1. Актуальность темы

В современном мире путешествия стали неотъемлемой частью жизни многих людей. Для эффективной организации поездок необходимо учитывать множество факторов: маршрут, расходы, даты, список необходимых вещей. Ручное планирование часто приводит к ошибкам и недопониманию. Веб-приложение для планирования поездок позволяет систематизировать весь процесс подготовки к путешествию.

### 1.2. Цель и задачи

**Цель:** разработать веб-приложение для планирования поездок.

**Задачи:**
- Проанализировать предметную область
- Спроектировать архитектуру приложения
- Разработать backend-часть
- Разработать frontend-часть
- Реализовать систему аутентификации
- Обеспечить возможность развёртывания в Docker
- Провести тестирование

## 2. Проектирование

### 2.1. Описание приложения

Приложение позволяет пользователям:
- Создавать поездки с указанием названия, направления, дат и бюджета
- Добавлять пункты маршрута с привязкой ко времени и дате
- Вести учёт расходов по категориям
- Составлять список вещей в чемодане

### 2.2. Архитектура

Приложение построено по клиент-серверной архитектуре:
- **Backend:** REST API на Django REST Framework
- **Frontend:** одностраничное приложение на React
- **База данных:** SQLite (разработка), PostgreSQL (продакшн)
- **Контейнеризация:** Docker + Docker Compose

## 3. Реализация

### 3.1. Backend

Backend реализован на Django с использованием Django REST Framework. Основные приложения:
- `accounts` — регистрация, авторизация, профиль
- `trips` — поездки, маршруты, расходы, список вещей

Аутентификация выполняется по JWT-токенам.

### 3.2. Frontend

Frontend разработан на React с использованием TypeScript. Основные страницы:
- Авторизация и регистрация
- Список поездок
- Создание/редактирование поездки
- Детальная страница поездки с маршрутом, расходами и чемоданом

## 4. Тестирование

Проведено функциональное тестирование основных сценариев:
- Регистрация и вход пользователя
- Создание поездки
- Добавление маршрута, расходов и вещей
- Проверка бюджета
- Развёртывание в Docker

## 5. Заключение

В ходе выполнения курсовой работы было разработано полноценное веб-приложение для планирования поездок. Приложение имеет клиентскую и серверную части, систему аутентификации, возможность развёртывания в Docker.
